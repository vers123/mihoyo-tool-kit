## 一、总体方针

依据 [优化点评估](file:///workspace/ai-docs/优化点评估.md) 的 18 项优化清单，按"性能优先包 / 工程化包 / 分发包"三档推进：

| 档位 | 范围 | 优先级 | 适用条件 | 本次结论 |
| --- | --- | --- | --- | --- |
| P 性能优先包 | O1 去浏览器 + O2 httpx + O4 跨平台 Cookie + O5 GUI 实时日志 + O10 print→logger | ★★★ 默认推进 | 提速与跨平台基础 | ✅ **启动**（用户选 P 档为主体） |
| E 工程化包 | O3 并发 + O6 SQLite 去重 + O7 tenacity + O8/O9 浏览器兜底提速 + O11 Pydantic + O13 CLI + O16 UA 池 | ★★ 推进 | 结构化与健壮性 | 🟡 **部分启动**：E1(asyncio) + E2(SQLite) 用户明确纳入；E3/E4/E5/E6/E7 依赖已放行，按 P/E1/E2 落地进度顺带做 |
| D 分发与部署包 | O12 Docker + 定时 + O14 RSS Feed + O15 HAR fixture + O18 Excel | ★ 推进 | 无人值守与对外分发 | 🟡 **仅 Excel 启动**（openpyxl 依赖放行）；D1 Docker / D2 RSS / D3 HAR fixture 未明确，搁置待追加 |

> 提问流程结论：范围=P 性能优先包（主体）；存储=SQLite；并发=接受 asyncio；依赖=全部放行（httpx/tenacity/pydantic/openpyxl）。即"以 P 档为骨架，明确追加 E1 asyncio 并发与 E2 SQLite 去重两项高价值工程化项，其余 E 档项随主线落地顺带推进；D 档仅做 Excel"。

## 二、P 档：性能优先包 — ✅ 已确认启动（主体）

### P1 = O1 + O2：抓取主路径去浏览器化 + httpx 化
- 新增 `core/api_client.py`：用 `httpx.Client`（连接池）直接请求三游戏 `content_v2_user` API。
- 修改 `fetchers/news/base.py`：`run()` 优先调 `api_client`；**仅 API 直连失败才回退启浏览器**（保留现有 Playwright 拦截路径）。
- 影响：`core/api_client.py`(新)、`fetchers/news/base.py`、`requirements.txt`(+httpx)。
- 收益：单游戏全量抓取预计从分钟级降到秒级。

### P2 = O4：Cookie 加载跨平台
- 修改 `utils/cookie_loader.py` `find_firefox_profile()`：增加 macOS / Linux 路径探测。
- 影响：`utils/cookie_loader.py`，无新依赖。

### P3 = O5：GUI 日志实时流
- 修改 `gui/workers.py` `ScraperWorker`：自定义 `redirect_stdout` 目标流，逐行 `log_message.emit`，而非任务结束一次性 emit。
- 影响：`gui/workers.py`，无新依赖。

### P4 = O10：print → logger
- `fetchers/`、`core/` 的 `print` 改为 `logger.info/warn`；logger 同时把记录转发给 GUI（与 P3 协同）。
- 影响：`fetchers/`、`core/`，无新依赖。

## 三、E 档：工程化包 — 🟡 部分启动（E1 asyncio + E2 SQLite 明确纳入）

> 提问确认：并发=接受 asyncio（E1 启动）；存储=SQLite（E2 启动）；依赖放行 tenacity/pydantic，故 E3/E5 可顺带做；E4 浏览器兜底提速与 P 档同源可做；E6 CLI / E7 UA 池按主线进度顺带。

### E1 = O3：三游戏并发
- `core/api_client.py` 提供 `async def fetch_all_games()`，`asyncio.gather` 并发三游戏。
- 风险：改动较大，需同步/异步双接口兼容（CLI 同步、未来调度异步）。

### E2 = O6：SQLite + post_id 去重
- 新增 `core/storage.py`：默认 SQLite（`data/news.db`，按游戏分表，主键 `iInfoId`），可选 JSON 导出。
- `extractors/` 增量去重改为 SQL 查询；`.txt` 作为可选导出格式保留。

### E3 = O7：tenacity 重试
- `utils/error_handler.py` 的自定义 `retry` 改用 `tenacity`（指数退避 + jitter）。

### E4 = O8 + O9：浏览器兜底提速
- `core/scraper.py` 增加 `page.route("**/*.{png,jpg,jpeg,gif,woff,css}", abort)`；`_scroll_for_data` 用 `page.expect_response` 替代 `time.sleep` 轮询。

### E5 = O11：Pydantic 数据建模
- 新增 `core/models.py`：`NewsItem` 模型，字段类型安全 + 中英重命名。

### E6 = O13：配置化 CLI
- `main.py` 增加 `--mode incremental`、`--workers N`、`--delay`、`--game genshin,zzz` 等参数。

### E7 = O16：UA 池 + 限流
- `core/api_client.py` 接入 `fake_useragent` 或内置 UA 列表；请求间隔 1–3s 随机。
