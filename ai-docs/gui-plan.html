一、项目现状与已完成工作

1.1 项目概述

米游社工具箱（miHoYo ToolKit）是一个基于 Playwright 的米游社与微博数据抓取工具。项目采用模块化架构，将「抓取」与「提取」分离，支持增量更新和自动备份。当前版本 v5.0.0，支持命令行（CLI）与 GUI 双模式交互。

项目已完成原神（中文/英文）、绝区零、星穹铁道四款站点的新闻抓取功能开发与验证。现在需要新增 GUI 图形界面，使项目支持双模式启动。

二、GUI 需求与设计目标

用户需求：为项目增加合适的 GUI 程序窗口界面，相关字体资源已放置在 resources/font/ 目录中。项目需支持命令行和 GUI 两种启动方式。

设计目标

  • 双模式启动：支持 python main.py（CLI）和 python main.py --gui（GUI）两种启动方式
  • 游戏主题化：利用 resources/font/ 中的游戏字体，为不同游戏导航项应用对应主题字体和配色
  • 功能全覆盖：GUI 界面覆盖现有 CLI 的全部 36 个功能选项
  • 非阻塞交互：抓取/提取等耗时任务在后台线程执行，界面不卡顿，实时显示日志输出
  • 向后兼容：CLI 模式完全保留，不受 GUI 新增代码影响
  • 解耦设计：GUI 代码作为独立 gui/ 模块，不修改现有 fetchers/extractors 逻辑

已确认的设计决策

  • 左侧导航栏布局（非顶部标签栏）
  • 浅色主题（非深色主题）
  • 全局底部日志面板（非每页独立日志）
  • 确定进度条 + 百分比 + 文字进度
  • 文本编辑配置（非表单方式）
  • 游戏字体用于导航项标题/装饰文字，正文用微软雅黑
  • 窗口默认 900x650，设置页可调整尺寸
  • 支持"停止"按钮中断任务
  • 窗口图标之后由用户提供 .ico 文件
资源说明 resources/font/ 包含四款站点的专属字体共 10 款（原神 6 款、星穹铁道 2 款、绝区零 2 款），每款提供 ttf/otf/woff2 三种格式。GUI 使用 ttf 格式通过 QFontDatabase 加载。

三、技术选型

选定 PySide6（Qt for Python 官方绑定）作为 GUI 框架。

选择理由

QFontDatabase 原生支持自定义字体加载；QSS 主题样式系统（类 CSS）可实现深色游戏主题；QThread + Signal 机制天然支持异步任务；QTabWidget 适合多标签页布局；LGPL 许可证适合开源项目。

对比结论

CustomTkinter 轻量但字体支持有限且样式能力弱；纯 Tkinter 内置但自定义字体加载困难。PySide6 在字体加载、主题样式和复杂布局方面优势明显，是最佳选择。

能力 PySide6 CustomTkinter 纯 Tkinter
自定义字体加载 QFontDatabase 原生 有限 弱
主题样式系统 QSS（类 CSS） 内置深色主题 无
多标签页 QTabWidget Tabview ttk.Notebook
异步线程 QThread + Signal threading threading
实时日志 QPlainTextEdit CTkTextbox Text

6.2 加载策略

# gui/theme.py

from PySide6.QtGui import QFontDatabase, QFont
from PySide6.QtWidgets import QApplication
import os

FONT_DIR = os.path.join(os.path.dirname(__file__), "..", "resources", "font")

GAME_TITLE_FONTS = {
    "genshin":  "Genshin Impact/Teyvat-Black/ttf/TeyvatBlack-Regular.ttf",
    "starrail": "Star Rail/Star-Rail-Neue/ttf/StarRailNeue-Sans-Regular.ttf",
    "zzz":      "ZenlessZoneZero/ZZZ-System/ttf/ZZZSystem-Regular.ttf",
}

GAME_BODY_FONTS = {
    "zzz": "ZenlessZoneZero/ZZZ-A/ttf/ZZZA-Regular.ttf",
}

def load_game_fonts() -> dict:
    """加载所有游戏字体到 QFontDatabase，返回 {key: family_name}"""
    loaded = {}
    for key, rel_path in {**GAME_TITLE_FONTS, **GAME_BODY_FONTS}.items():
        font_path = os.path.join(FONT_DIR, rel_path)
        if os.path.exists(font_path):
            font_id = QFontDatabase.addApplicationFont(font_path)
            if font_id != -1:
                families = QFontDatabase.applicationFontFamilies(font_id)
                if families:
                    loaded[key] = families[0]
    return loaded

def get_title_font(game_key: str, fonts: dict, size: int = 18) -> QFont:
    family = fonts.get(game_key, "Microsoft YaHei")
    return QFont(family, size, QFont.Bold)

八、异步任务处理

抓取和提取任务可能耗时数分钟（如绝区零 173 页 API 请求共 1554 条），必须在后台线程执行，否则界面会冻结。使用 PySide6 的 QThread + Signal 机制：

# gui/workers.py

from PySide6.QtCore import QThread, Signal
import io
from contextlib import redirect_stdout

class ScraperWorker(QThread):
    """抓取/提取任务后台线程"""
    log_message = Signal(str)       # 日志信号
    finished_ok = Signal(bool, str)  # 完成信号 (success, message)

    def __init__(self, func, *args, **kwargs):
        super().__init__()
        self.func = func
        self.args = args
        self.kwargs = kwargs

    def run(self):
        log_buffer = io.StringIO()
        try:
            with redirect_stdout(log_buffer):
                self.func(*self.args, **self.kwargs)

            for line in log_buffer.getvalue().split('\n'):
                if line.strip():
                    self.log_message.emit(line)

            self.finished_ok.emit(True, "任务完成")
        except Exception as e:
            self.log_message.emit(f"[ERROR] {e}")
            self.finished_ok.emit(False, str(e))
关键技术点
  • stdout 重定向：现有 fetchers/extractors 大量使用 print() 输出日志，通过 redirect_stdout 捕获并转发到 GUI 日志区，无需修改业务代码
  • 信号机制：Worker 线程通过 Signal 安全地更新 UI（Qt 禁止跨线程直接操作 UI）
  • 按钮状态管理：任务执行时禁用相关按钮，完成后恢复，防止重复操作
  • 中断支持：通过 QThread.requestInterruption() 支持用户取消任务（需 fetchers 配合检查）
